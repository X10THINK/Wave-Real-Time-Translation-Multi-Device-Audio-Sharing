# Instructions for AI development assistants

Read [Project Context](PROJECT_CONTEXT.md), [Project Status](PROJECT_STATUS.md), [PRD](../PRD/PRD_Complete.md), [SRS](../SRS/SRS_Complete.md), [TRD](../TRD/TRD_Complete.md) and [ADRs](../Other_Documents/ADR_Architecture_Decision_Records.md) before proposing code changes.

1. Verify repository code and tests before claiming a feature is implemented.
2. Preserve requirement IDs and distinguish LOCKED/TARGET/PROPOSED/OPEN.
3. Treat documents as working drafts unless separately approved.
4. Describe affected files, test plan, migration risks and documentation updates in PRs.
5. Do not expose secrets or make irreversible infrastructure changes without explicit authorization.
6. Keep implementation decisions in ADRs and update the decision log.
